## 📌 Описание проекта

Консольное приложение на Python для **управления списком игроков**.

Программа позволяет:

- добавлять игроков
- удалять игроков
- искать игрока по имени
- повышать уровень
- сортировать игроков по уровню

Данные хранятся в двух списках:

- список имён (`names`)
- список уровней (`levels`)

---

## 🚀 Функциональность

Меню программы:

1 — добавить игрока  
2 — показать всех игроков  
3 — удалить игрока  
4 — поиск игрока по имени  
5 — повысить уровень  
6 — сортировка игроков  
7 — выход  

### Возможности

- добавление нового игрока (имя + уровень)
- отображение списка игроков
- удаление игрока по номеру
- поиск игрока по имени
- повышение уровня игрока
- сортировка игроков по уровню (пузырьком)

## 🧭 Как пользоваться

После запуска программы появится меню.

### Добавление игрока

Введите имя и уровень игрока.

### Просмотр игроков

Выводится список игроков в формате:

```
1 Alex - 10
2 Bob - 5
```

### Удаление игрока

Введите номер игрока из списка.

### Поиск игрока

Введите имя — программа найдёт игрока (если он есть).

### Повышение уровня

Введите номер игрока и количество уровней для повышения.

### Сортировка

Игроки сортируются по уровню (от меньшего к большему).
